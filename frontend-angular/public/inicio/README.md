# Imágenes — Página de Inicio

Coloca aquí las imágenes para la página principal.

## Estructura esperada

```
inicio/
  hero.jpg          ← Imagen principal del hero (recomendado: 1600×900px)
  sede-bachillerato.jpg   ← Foto sede Bachillerato (800×500px)
  sede-primaria.jpg       ← Foto sede Básica Primaria (800×500px)
  sede-rural.jpg          ← Foto sede Rural Los Sauces (800×500px)
```

## Notas
- Formato: JPG preferido (mejor compresión)
- Peso máximo recomendado: 500 KB por imagen
- Las imágenes se sirven directamente desde Vercel CDN
